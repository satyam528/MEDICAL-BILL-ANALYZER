# 🏥 Medical Bill Analyzer

An AI-powered application that analyzes medical bills and converts complex billing information into a simple, structured, and easy-to-understand summary.

Built with **Python and Streamlit** and deployed on **AWS**.

## 🚀 Features

* 📄 Upload and analyze medical bills
* 🤖 AI-powered bill analysis
* 💰 Extract and organize billing information
* 📊 Generate easy-to-understand summaries
* 🔍 Identify important charges and medical bill details
* ☁️ Deployed on AWS
* 🖥️ Simple and interactive Streamlit interface

## 🛠️ Tech Stack

* **Python** — Core programming and data processing
* **Streamlit** — Web application interface
* **AI/LLM** — Medical bill analysis and summarization
* **AWS** — Cloud deployment

## 🔄 How It Works

```text
Medical Bill
     ↓
Upload Document
     ↓
Extract Bill Information
     ↓
AI Analysis
     ↓
Process & Summarize Data
     ↓
Clear, Structured Results
```

## 🎯 Objective

Medical bills often contain complicated charges, descriptions, and medical terminology that can be difficult to understand.

The goal of this project is to simplify medical billing information by using AI to analyze the bill and present the key information in a clear and understandable format.

## ☁️ Deployment

The application is deployed on **AWS**, providing practical experience with cloud deployment and hosting a Python-based application.
